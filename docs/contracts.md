# Контракты

Источник истины: `src/hopiumcode/models.py` (данные) и `src/hopiumcode/interfaces.py` (интерфейсы).
Идентификатор фрагмента: `path::qualified_name` или `path::#N`. Формат ссылки в ответе: `[путь:начало-конец]`.
Типы узлов графа: File, Class, Function, Doc. Типы рёбер: DEFINES, CALLS, IMPORTS, INHERITS, DOCUMENTS.
