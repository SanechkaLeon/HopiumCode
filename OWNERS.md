# Зоны ответственности

Имена исполнителей проставляет команда. Изменения в чужой зоне только через pull request с согласованием владельца.

| № | Зона | Папки и файлы | Исполнитель |
|---|---|---|---|
| 1 | Архитектор-интегратор, оркестратор | `config.py`, `models.py`, `interfaces.py`, `prompts.py`, `orchestrator.py`, `cli.py`, `mcp_client.py` (вместе с 4) | ________ |
| 2 | Индексация и векторный поиск | `indexing/`, `retrieval/lexical.py` | ________ |
| 3 | Граф кода и гибридный ретривер | `graph/`, `retrieval/hybrid.py` | ________ |
| 4 | MCP-сервер и инструменты | `mcp_server/`, `mcp_client.py` (вместе с 1) | ________ |
| 5 | Оценка, тесты, документация | `eval/`, `tests/`, `docs/`, README | ________ |

Контракты (`models.py`, `interfaces.py`) меняет только участник 1 после согласования со всеми.
